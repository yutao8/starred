# 🌟 GitHub Starred Projects & 趋势洞察

> 本项目是一个**智能化 GitHub 收藏仓库管理与多维趋势分析系统**。  
> 自动同步 Starred 仓库，结合大语言模型生成高质量中文技术摘要与标签，并基于历史快照追踪每个项目的 Star / Fork 演进轨迹，提供多维趋势排行与交互式 Web 看板。

## ✨ 项目核心特色

- 🤖 **AI 深度解析与标签**：获取 Star 列表时，结合大模型（DeepSeek / OpenAI / OpenRouter）自动生成地道技术解析与语义标签，告别“只收藏不理解”。
- 📈 **长期历史演进追踪**：支持多版本快照差分，为每个项目建立专属历史履历（`repos/{id}.json`），精准还原每个项目的 Star 与 Fork 演进走势。
- 🔥 **多维度趋势洞察与热度分析 (`trend.php`)**：
  - **综合热度榜**：整合 Star 增量、增长率、Fork 增量、日均增量加权评分。
  - **Star 增长率榜**：支持 `--min-stars` 最低门槛过滤，精准捕捉爆发型黑马。
  - **增量与日均榜**：绝对增量、Fork 增量、日均新增等多维排行。
  - **语言宏观趋势**：聚合统计各编程语言生态的整体增长态势。
- 📦 **全格式输出与历史归档**：每次分析同时输出结构化 `trend.json`、原生渲染 `trend.md`，并自动归档至 `trend_history/` 时间戳目录。
- 💻 **全站联动 Web 看板**：
  - `index.html`：按语言与标签快速检索项目大厅。
  - `trend.html`：多维排行看板、历史分析快照浏览器，支持深/浅色模式。
  - `history.html`：基于 ECharts 的交互式项目 Star/Fork 增长轨迹图。

## 🚀 快速使用

### 1. 环境准备
确保已安装 PHP 8.2+ 及 `curl`、`json`、`mbstring` 扩展，配置好 `.env`（详见 [DEPLOY.md](DEPLOY.md)）。

### 2. 命令行操作

```bash
# 1. 抓取最新 Star 列表并生成 AI 中文解析
php fetch.php

# 2. 同步 dist/ 快照至单项目历史履历库 (repos/)
php history.php

# 3. 运行趋势分析（默认 7 天窗口，Top 20，≥500 星门槛）
php trend.php

# 4. 常用趋势分析参数：
php trend.php --days=14 --top=30 --min-stars=1000   # 14天窗口，Top 30，门槛 1000 星
php trend.php --lang=Python                        # 仅筛选 Python 语言项目
php trend.php --sync --force                       # 先同步最新快照，并忽略缓存强制重算
```

### 3. Web 浏览
使用任意静态 Web 服务器（或 PHP 内置服务器 `php -S localhost:8000`）打开：
- `index.html`：项目检索大厅
- `trend.html`：多维趋势排行榜与历史看板
- `history.html`：单项目历史增长折线图
